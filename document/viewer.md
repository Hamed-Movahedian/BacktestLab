# تعریف وب سرویس:
- این وب سرویس به صورت است:
```bash
curl -X 'POST' \
  'http://127.0.0.1:8000/api/backtest/get_back_test' \
  -H 'accept: */*' \
  -d ''
```
- فعلا هیچ ورودی ندارد ولی در آینده ورودی ها هم تعریف می شوند.
