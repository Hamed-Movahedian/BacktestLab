# هم‌نمودار | طلای ۱۸ عیار و صندوق عیار

یک رابط فارسی با تم تیره، ساخته‌شده با React، TypeScript و TradingView Lightweight Charts **5.3.0**. برنامه پس از باز شدن دو فایل نمونهٔ **ساختگی** را نمایش می‌دهد. برای دیدن دادهٔ واقعی خود، هر دو CSV را در ورودی مربوط انتخاب کنید. فایل‌های انتخابی به هیچ سروری ارسال نمی‌شوند.

## اجرا در حالت توسعه

پیش‌نیاز: Node.js 20.19+ در شاخهٔ ۲۰، یا Node.js 22.12+.

```sh
npm ci
npm run dev
```

نشانی‌ای را که Vite نشان می‌دهد در مرورگر باز کنید (معمولاً `http://localhost:5173`). برای آزمون‌ها `npm test` و برای ساخت نسخهٔ تولید `npm run build` را اجرا کنید. خروجی `dist/index.html` یک فایل HTML مستقل است که بدون Node.js، سرور یا CDN در مرورگر قابل اجراست.

## فرمت CSV

فایل UTF-8 (با یا بدون BOM) باید سطر عنوان داشته باشد. جداکننده می‌تواند کاما، نقطه‌ویرگول یا تب باشد. نمونه:

```csv
date,time,open,high,low,close,volume
1404/08/27,11:30,100,106,98,104,250
1404/08/27,11:35,104,108,103,106,310
```

- می‌توانید از نام ستون‌های فارسی مانند `تاریخ,زمان,قیمت باز شدن,حداکثر قیمت,حداقل قیمت,قیمت بسته شدن,حجم معامله` هم استفاده کنید. ارقام فارسی، عربی و لاتین پذیرفته می‌شوند.
- تاریخ و ساعت را می‌توان در یک ستون `datetime` یا `timestamp` آورد؛ مثلاً `2025-11-18T08:00:00Z` یا `۱۴۰۴/۰۸/۲۷ ۱۱:۳۰`. زمان یونیکس ۱۰رقمی (ثانیه) و ۱۳رقمی (میلی‌ثانیه، روی ثانیهٔ کامل) نیز در ستون `timestamp` پذیرفته می‌شود.
- زمان بدون اختلاف UTC صریح، زمان تهران فرض می‌شود. برای فایلِ UTC از `Z` استفاده کنید. اختلاف‌های تاریخی تهران اعمال می‌شوند؛ برای ساعت مبهم یا ناموجود هنگام تغییر ساعت رسمی، اختلاف UTC را صریح بنویسید. سال ۱۲۰۰ تا ۱۵۹۹ به‌عنوان شمسی و سال ۱۷۰۰ تا ۹۹۹۹ به‌عنوان میلادی خوانده می‌شود.
- ترتیب ردیف‌ها می‌تواند نامرتب باشد؛ زمان تکراری، تاریخ نامعتبر، حجم منفی و OHLC ناسازگار خطا می‌دهند. اگر اعداد گروه‌بندی‌شده حاوی کاما هستند، آن سلول را در گیومه بگذارید. سقف اندازهٔ هر فایل ۱۶ MiB است.
- تایم‌فریم و مبنای زمان کندل (ابتدا یا انتهای بازه) باید در دو فایل یکسان باشند. برنامه کندل را تغییر تایم‌فریم نمی‌دهد و واحد قیمت را تغییر نمی‌دهد. اگر هیچ زمان دقیقی مشترک نباشد، هشدار نمایش می‌دهد.
- دو فایل نمونه در پوشهٔ `samples/` هستند. در رابط هم از «راهنمای CSV» دانلود می‌شوند.

## رفتار پنل‌ها

دو پنل بومی یک `createChartEx` مشترک‌اند؛ دو سری با `chart.addSeries(CandlestickSeries, options, paneIndex)` اضافه شده‌اند. بنابراین حرکت، زوم و خط عمودی نشانگر روی زمان مشترک است. مقیاس قیمت‌ها مستقل است و می‌توان جداکنندهٔ دو پنل را کشید. با رفتن نشانگر روی کندل، OHLC و حجم آن زمان به‌روزرسانی می‌شود. «نمایش کل داده» بازهٔ زمانی را به کل داده و مقیاس قیمت‌ها را به حالت خودکار برمی‌گرداند.

هم‌ترازی روی **اجتماع زمان‌های دو فایل** است: اگر در زمانی فقط یک نماد داده دارد، سری مقابل یک `WhitespaceData` با همان زمان دریافت می‌کند، بدون کندل یا حجم ساختگی. بازه‌هایی که هیچ‌یک داده ندارند (مثلاً شب بین دو روز) نقطه‌ای روی محور ندارند؛ فاصلهٔ افقی بر اساس تعداد موقعیت‌های نمودار است، نه مدت پیوستهٔ تقویمی.

| فایل | مسئولیت |
| --- | --- |
| `src/csv.ts` | خواندن، اعتبارسنجی و هم‌تراز کردن CSVها |
| `src/time.ts` | نرمال‌سازی تاریخ ورودی و نمایش شمسی در منطقهٔ `Asia/Tehran` |
| `src/tehran-scale.ts` | تنظیم نقاط روز، ماه و سال روی محور شمسی |
| `src/ChartBoard.tsx` | پنل‌ها، نمودار، و اطلاعات نشانگر |
| `tests/data.test.ts` | آزمون ورودی‌ها، زمان و هم‌ترازی |
