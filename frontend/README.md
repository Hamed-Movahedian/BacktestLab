# Backtest Lab frontend

رابط React و TypeScript برای نمایش بک‌تست.

```bash
npm install
npm run dev
```

صفحه در `http://localhost:3000` و سرویس در `http://127.0.0.1:8000` اجرا می‌شود. برای تغییر آدرس سرویس، متغیر `VITE_API_BASE_URL` را در فایل `.env.local` تنظیم کنید. اجرای `npm run build` ساخت پروژه را بررسی می‌کند. تعداد کندل خالی یعنی همه داده‌ها؛ در غیر این صورت مقدار باید حداقل ۱۰۰ باشد.
